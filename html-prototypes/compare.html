Compare

On each filesystem: unpack an archive, pack the tree again, copy the archive onto the mount, and list that copy. A local directory is the floor.

Is it actually faster? Yes. On a 5,868-file tree the default mount unpacks 13x faster than s3fs and 7x faster than NFS, and packs 15x and 10.5x faster. On large files the lead is narrower but still clear — and against S3 itself, DuckDB runs 4.5x and 45x faster through the mount. The charts below are the evidence.

The field: local directory (the floor), kvfs (our ancestor, an in-memory filesystem on Redis/Valkey), fs-relay (the default mount), fs-relay -post, s3fs on rustfs, and fuse-nfs (NFS through FUSE).

DuckDB over the mount vs S3

Both tables above run fs-relay and s3fs through FUSE. A separate run removes that doubt: DuckDB reads the same partitioned parquet once through the fs-relay mount and once straight from rustfs over S3, with no FUSE on the S3 path. Each query starts cold — fresh DuckDB session, external file cache off, kernel page cache dropped, daemons restarted. The mount is still substantially faster, so the lead is not FUSE overhead on s3fs.

Why it is fast

Zero-copy Linux kernel features, where the bytes skip the allocate, read, copy, write, and free cycle — and on large files a context switch per block:

  • splice(2): file to pipe to socket on reads, socket to pipe to file on writes. See Raw path.
  • copy_file_range(2): server-side copy between two open files, one call.

Earlier designs (for developers)

Do not bring these back. They were measured, and they stayed out.

  • MessagePack was the first wire format. FlatBuffers replaced it: on the Ansible tree, -ws with FlatBuffers was about 15% faster unpacking and 6% faster packing; on Antigravity, 11% faster at both.
  • JSON can carry file bytes as multipart/form-data: one application/json part for the call, one application/octet-stream part for the bytes. On the Ansible tree that plain-text body kept up with MessagePack and FlatBuffers. It is not in the server — one body shape is the smaller program.
